# Freelancer Project Management System

A web application that helps freelancers and clients manage projects in one place: posting projects, tracking progress, and handling work from start to finish.

## Features

- Freelancer and client registration and login
- Post and browse projects
- Project status tracking
- Responsive user interface

## Tech Stack

- **Frontend:** React (Vite), HTML, CSS, JavaScript
- **Backend:** Java
- **Database:** MySQL

## Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/deepajothimuthapudaiyar/Freelanncer.git
   ```
2. Go to the frontend folder
   ```bash
   cd freelancer-project/freelancer-project/frontend
   ```
3. Install dependencies and run
   ```bash
   npm install
   npm run dev
   ```
4. Open `http://localhost:5173` in your browser
